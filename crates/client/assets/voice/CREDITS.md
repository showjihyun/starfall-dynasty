# Voice lines

Generated by `python tools/voice.py` (docs/STORY.md §8): speech by [MeloTTS](https://github.com/myshell-ai/MeloTTS)
Korean (MyShell.ai, MIT licence, code and weights), then pitch and effect per speaker with ffmpeg
(presets in `voices.json`). The lines are the game's own text (`assets/cinematics/opening.ron`, `comms.ron`).
`manifest.json` records the generator version and each line's length; do not edit the .ogg files by hand —
change the text or the preset and run the tool again.
