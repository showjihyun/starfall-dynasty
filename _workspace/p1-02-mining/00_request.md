## 분류
- 유형: SLICE

- 의미: **첫 경제 행동과 첫 역사 기록.** p1 종료 기준은 "핵심 행동이 서버 판정 + 역사 기록으로 동작" 인데 p1-01 에는 역사 기록이 없었다(이동은 역사 이벤트가 아니다). 이 슬라이스가 **역사 엔진을 처음 실제로 쓴다** — 지금 코드에는 역사 크레이트·테이블·계약이 하나도 없다.

## 범위 (초안 — Phase 2 에서 architect·designer·history 가 확정한다)

포함:
- **채굴 대상**: cradle 성계에 채굴 가능한 지점(행성 표면 또는 소행성대 — designer 가 정한다). 광물 종류는 **소수**로 시작한다(GDD 비판 리뷰의 "10,000 광물" 경고).
- **채굴 명령**: 클라이언트는 의도만 보내고 서버가 거리·쿨다운·매장량을 판정한다(절대 원칙 1). 산출량은 **결정적**이다 — 같은 입력이면 같은 결과(원칙 9).
- **인벤토리**: 정수 수량, 서버 권위. **같은 명령을 두 번 보내도 한 번만 반영**된다(멱등, 복사 방지).
- **도메인 이벤트**: 채굴마다 도메인 이벤트. **이것 자체는 역사적 사건이 아니다**(원칙 4).
- **역사 엔진 첫 골격**: 도메인 이벤트 → 중요도 판정(`rule_version` 기록) → Historical Event + Evidence. 첫 규칙은 **한 종류의 광물이 성계에서 처음 채굴되면 `MINERAL_DISCOVERED`(Level 2 Regional)**. 판정은 결정적·멱등·추가 전용(원칙 5·9).
- **클라이언트(그레이박스)**: 채굴 조작, 인벤토리 표시, 최초 발견 알림.
