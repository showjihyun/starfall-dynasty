# p1-02-mining — 마이그레이션 동결 선언

규칙: ADR-0007 §5 (리더 결정 2026-09-28, 선언 위치 2026-09-29). 증거 DB `starfall` 로 서버를 띄우면
서버가 아직 적용되지 않은 마이그레이션을 **적용해 버리고**, 적용된 파일은 그 순간 동결된다(고치면 다음
기동이 체크섬 불일치로 막힌다). 그래서 **아직 적용되지 않은** 마이그레이션은 그 소유자가 아래에
한 줄을 적은 뒤에만 증거 DB 로 서버를 띄운다.

- 형식(한 줄, 이 형식 그대로): `frozen: NNNN — <소유자>, <YYYY-MM-DD>`
- 적는 사람: **그 마이그레이션 파일의 소유자만**. 기동하는 사람이 대신 적지 않는다.
- 검사: `tests/e2e/server_boot.py` 의 모든 실서버 기동이 `_sqlx_migrations` 와 `server/migrations/*.sql`
  을 대조하고, 미적용 파일에 선언 줄이 없으면 exit 4 로 멈춘다. 통과하면 선언 줄의 `경로:줄` 을 증거
  JSON `migration_freeze` 에 싣는다.

이미 적용된 0001~0003 은 선언 없이 동결이다(적용 = 동결; 0002·0003 은 2026-09-28 13:15 UTC 증거 DB 적용).
