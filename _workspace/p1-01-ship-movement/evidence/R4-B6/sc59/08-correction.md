**원 기록은 고치지 않는다**(절대 원칙 5의 정신 — 정정은 새 레코드로 남긴다).

## 정정 1 — `07-recording-index.md`의 "HUD가 보이도록 잘랐다"는 **사실이 아니다**

- 내가 적은 것: 색인 프레임 6장을 "HUD가 보이도록 좌상단 1146×720으로 잘랐다".
- **실제**: qa3가 확인한 결과 **6장 전부 Claude Code 터미널 창**이고 HUD가 아니다.
- **왜 틀렸나**: 나는 프레임을 뽑기만 하고 **한 장도 열어 보지 않았다.** 토큰을 아끼려고
  "HUD는 Game view 좌상단이니 이 크롭이면 들어간다"고 **추론한 것을 관측처럼 적었다.**
  이 슬라이스가 내내 붙잡아 온 오류를 내가 증거 문서에서 저질렀다(계약 §7a).

## 정정 2 — 클립 a 순간에 **화면에 HUD가 없었다**

- qa3 실측: 클립 a(W 8초) 시점 `t ≈ 213 s`의 Game view에 **HUD 텍스트가 한 줄도 없다**
  (`right-t205s.png`·`right-t213s.png`).
- 계약 SC-59가 스스로 적은 실격 조건: *"형식보다 내용이 판정한다 — 화면에 입력 상태가
  떠 있지 않으면 그 영상은 부호를 증명하지 못한다."* → **녹화는 (a)를 증명하지 못한다.**
- 내가 사용자에게 받은 **관찰 진술("뱃머리 방향으로 잘 나간다")은 그대로 유효**하지만,
  계약이 요구한 **영상 증거가 없다.**
- 부수: tick↔영상 시각 대응은 qa3가 확정했다 — `t_video = 600 − (463630 − tick)/20`.

## 정정 3 — "평범하게 비행하다 끊겼다"는 **관측과 다르다**

- 내가 `06-finding-protocol-violation.md`에 적은 것: *"사용자는 치트나 비정상 조작을 하지 않았고
  평범하게 비행했다"*, *"정상 플레이가 강제 종료로 이어졌다"*.
- **실제**: 위반 tick 457993을 사이에 둔 프레임 t=300 s(터미널)·t=320 s(Chrome), 그리고
  t=270·340·360 s **전부 Unity가 전경 창이 아니다**(`contact-250to360.png`).
  **"평범한 비행 중"이 아니라 "Editor가 백그라운드인 동안"이다.**
- **결함이라는 판단은 유지된다** — 백그라운드에서도 서버에 붙어 있는 클라이언트가 강제 종료되는 것은
  정당하지 않다. 다만 **재현 절차와 고칠 자리가 달라진다**(Editor 백그라운드 → 프레임 지연 → catch-up 버스트).
  client가 확정한 원인(`GreyboxSession.cs:418~452`의 상한 없는 catch-up 루프)과 **오히려 더 잘 맞는다.**

## qa3가 새로 찾은 관측 (내 기록에 없던 것)

- `t = 600 s` 프레임의 Unity 상태 바: **`starfall.net: outbound queue full (256), refusing to send`**
  (`statusbar-t600s.png`). 송신 큐가 상한까지 차서 송신을 거부하고 있었다 —
  "밀린 입력이 한꺼번에 나간다"와 형태가 일치한다. **위반 이후 구간의 관측이므로 정황이고, 인과는 미판정.**
- **재조정 수치가 내 기록보다 나쁘다.** 카운터가 재접속에서 초기화된다(`ack_input_seq` 7081 → 5308).
  tick 463630 실측 `reconcile_hard_snap_total = 3`, `reconcile_error_m max = 323.1212`, n = 2627.
  → **세션 전체 hard snap 최소 8건**(5+3), **위치 오차 최댓값은 56 m가 아니라 최소 323 m.**
  단 `reconcile_error_deg max`만 재접속 전후가 **80.5663으로 동일** — 초기화되지 않거나 포화될 수 있어
  **지표 자체를 먼저 확인해야 한다.**

## 내가 고칠 절차 (다음 SC-59 촬영에 적용)

1. **찍기 전에 프레임을 한 장 뽑아 열어 본다** — HUD가 실제로 보이는지 확인하고 시작한다.
2. **Unity를 전경에 둔다.** 녹화 중 다른 창으로 넘어가지 않는다.
3. 사용자 진술을 받을 때 **수치를 함께 받는다**(HUD 값 그대로).
4. 내가 관측하지 않은 것을 관측처럼 적지 않는다. 추론이면 추론이라고 적는다.
