# p1-04-visual-baseline

## 요청 원문
"다 되면 우주 배경, 함선의 여러 모습, 자원 채취 시설 등을 매우 고 퀄리티로 모델링 해줄 수 있을까? 관련 도구가 필요하다면 설치도 해줘. 이거 먼저 해야 할거 같아. 지금은 전혀 게임 같은 느낌이 없네." (2026-10-07)

## 사용자 결정 (2026-10-07)
- 시작 시점: **병행 시작** — Unity 밖 작업(아트 방향·에셋 수집·Blender 모델링)은 지금, Unity 안 작업(셰이더·씬 배치·임포트)은 p1-03 r1 종료 뒤.
- 에셋 출처: **무료 CC0 팩 + 다듬기**, **Blender 스크립트로 직접**. (유료 구매·AI 생성은 쓰지 않음)
- 도구: Blender 설치(winget, 리더가 실행).

## 분류
- 유형: SLICE (techart 첫 투입). 로드맵 p1 — "1 성계, 1 행성, 1인 함선"의 비주얼 기준선. 범위 게이트 안(대형 함선·다수 성계 아님).
- 목표: 그레이박스 → "게임처럼 보이는" 기준선. 기능 변경 없음(서버·계약 불변).

## 범위 초안
- 우주 배경: 스카이박스(별·성운), 항성 1(Cradle) + 조명·블룸, 행성 1(MVP-1 의 "1 행성" — 처음 만든다).
- 함선: Scout S-01 기준 스케일 확정, 외형 변형 여러 개(선체 variant·색·모듈 소켓). 원격 함선과 내 함선 구분.
- 자원: 광맥 8곳 → 소행성 메시(광물별 색·재질), 채굴 빔/채굴 시설 표현.
- 정거장: Cradle Exchange.
- 성능: 1080p 60 fps 예산(space-3d-rendering §8) 측정.
- 화면 요소 규칙(screen-elements) 적용 — 새 시각 요소도 UI-nn 표와 사람 체크.

## 제약 (p1-03 r1 과 병행이라서)
- **r1 동결 전·중에는 `client/` 아래를 건드리지 않는다.** 결과물은 레포 루트 `art/` 스테이징(원본 .blend, 생성 스크립트, 내보낸 .fbx/.glb, 라이선스 기록)에 둔다. Unity 임포트는 리더가 r1 종료를 알린 뒤.
- CC0 만. 에셋마다 출처 URL·라이선스·받은 날짜를 `art/LICENSES.md` 에.
- 큰 바이너리는 LFS(.gitattributes 에 fbx/glb/blend/png 등록됨).
