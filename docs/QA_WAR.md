# 장기 전쟁 QA (살아 있는 세계)

`cargo run -p sim --release --example war -- --hours 24` — 동맹 여러 개의 AI 함장이 게임 시간으로 몇 시간–며칠 동안 실제 규칙
(해적·광석 판매로 영향력, 지배선 60, 시간당 감쇠 3%, 세금, 유지비, 과확장, 전쟁·교전)으로 성계를 다툰다(`sim::war`).
매 시간 동맹별 보유 성계·금고, 주인이 바뀐 횟수, 한 동맹의 최대 점유율, 선두 교체, 동맹·성계별 손실, 연대기 사건 수를 보고한다.
테스트 `crates/sim/tests/war.rs`(1시간 · 결정성). 24시간 한 판 벽시계 약 4–5분.

맹주 전략(읽기 쉬운 규칙): 모항 장악 → 가장 가까운 미보유 성계로 확장 → 흔들리는 보유 성계 방어. 가장 많이 가진 동맹이
우리보다 많으면, 또는 목표 성계의 주인에게 선전포고. `--war-hours`(6) 동안 땅을 못 늘리면 강화. 함장은 사냥꾼(목표 성계의 해적과
전쟁 중인 적)과 광부(채굴·판매, 응사) 반반. 플레이어처럼: 무고한 중립 함장은 쏘지 않고, Wild에서 중립 함장이 포탑 사거리에 있으면
방아쇠를 놓는다(대상 패널의 「함대 아님」 경고 — 포탑의 빗나간 사격은 설계), 적 함장이 정거장 2500 u 안에 있으면 출항하지 않는다.

## 핑퐁·소모전 진단 (2026-11-08)

보고서에 원인별 숫자를 넣었다: 한 시간 안 재탈환을 「무주지를 거쳐」와 「다른 동맹에게서」로 나누고, 손실을 (성계, 죽은 쪽, 죽인 쪽)으로 센다.

1. **재탈환 149 = 다른 동맹에게서 99 + 무주지를 거쳐 50.** 함락한 쪽이 바로 다음 목표로 떠나고, 밀려난 동맹의 영향력이 그대로 남아
   되찾기가 쉬웠다. → 규칙 `social.conquest_purge 0.5`: 다른 동맹에게 넘어가면 이전 주인의 영향력이 절반(사양 `station_siege`: 49.5 → 24.8).
   AI는 남이 다투던 성계를 얻으면 30분 지킨다.
2. **평화 중의 학살(Hollow Crown, ORN↔KHZ 837)은 버그였다.** 그리드의 「사냥 중」 표시(대상을 쫓는 NPC)가 해적을 쫓는 **호위함**에도
   켜져, 옆 함장의 포탑이 그 호위함을 자기를 노리는 해적으로 보고 쐈고 앙갚음이 이어졌다. → 표시는 NPC만. 호위함 포탑은 방아쇠가 당겨져
   있어도 NPC와 전쟁 상대만 쏜다(플레이어는 호위함의 방아쇠를 놓을 수 없다). 테스트 `escort_turrets_leave_bystanders_alone`.
