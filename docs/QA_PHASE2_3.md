# QA — Phase 2·3 플레이 체크리스트

순서대로 하면 기획안 수직 슬라이스(발굴 → 계약 → 배신 → 격침 → 잔해 조사 → 위조와 폭로 → 보도)를 한 번에 지나간다.

## 자동 실행 (기본)

사람이 하지 않아도 된다. 헤드리스 함장 둘이 실제 `--dev` 서버에 소켓으로 접속해 아래 체크리스트를 플레이하고, 서버가 보낸 데이터로 항목마다 PASS/FAIL을 판정한다(약 35초, 결정적).

```
cargo build --release -p server
cargo run -p bot --release --example qa                       # 항목별 PASS/FAIL 출력
cargo test -p bot --release --test qa                          # 같은 것을 테스트로(전 항목 통과해야 함)
cargo run -p bot --release --example qa -- --keep --data DIR   # 끝난 세계를 띄워 둔다(포트 7790) + DIR/qa_tokens.txt
client --server ws://127.0.0.1:7790 --name QA-B --token <qa_tokens.txt의 토큰> --auto --script "station 1" --shot s.png --shot-at 7
```

`--keep` 뒤에는 클라이언트로 그 세계의 각 창(정거장·연대기·동맹·계약)을 찍어 화면을 확인한다. 클릭이 필요한 화면(로그인·캐릭터 생성)은 `client --clicks "x,y@초;…"`로 실제 마우스 클릭과 같은 경로를 재현한다.

개발 서버 전용 QA 명령: `/cash`, `/grow N`, `/influence N [성계]`, `/tp station|wreck|poi:<종류>`.

## 사람이 직접 할 때

### 준비 (리드가 띄움)

```
server --dev --data data/qa-session --record data/qa-session/rec --metrics data/qa-session/metrics.jsonl
client --name QA-A        # 창 1: 고고학자
client --name QA-B        # 창 2: 기자
```

- 기록이 남으므로 문제가 생기면 시각만 알려 주면 된다. `client --replay data/qa-session/rec --as QA-A --from <초>`로 그 장면을 다시 본다.
- 개발 명령(채팅창에 입력): `/cash`(자금), `/grow N`(모든 모듈 Lv N), `/influence N [성계번호]`.
- 키: U 정거장 · J 임무 · **O 계약** · H 연대기 · L 동맹 · M 지도 · V 스캔/조사 · G 도킹 · T 목표 · Space 사격.

### 체크리스트

자동 실행의 항목 번호와 같다. 각 항목에서 **기대 결과와 다르면** 메모: 항목 번호, 무엇이 보였는지, 대략의 시각.

#### 1. 캐릭터 생성 (2분)
- [ ] 1-1 직업 7개(탐험가·광부·상인·전투 조종사·역사학자·**고고학자**·**기자**)가 설명과 함께 보인다.
- [ ] 1-2 창 1은 **Archaeologist + Seer**, 창 2는 **Journalist + Talon**으로 진수.

#### 2. 고고학 (8분) — 창 1
- [ ] 2-1 `/cash`, `/grow 5` 입력 → 지갑·함선 등급이 바뀐다.
- [ ] 2-2 M 지도에서 **Hollow Crown**으로 워프(정거장에서 G로 출항 후).
- [ ] 2-3 지도에서 고대 유적(♜)으로 날아가 가까이서 V(스캔) → 「유물 발굴: 미감정 유물 (…)」 알림.
- [ ] 2-4 정거장 도킹(G) → U 정거장 창 아래 **유물** 섹션에 미감정 유물이 보이고, 이름·가치는 숨겨져 있다.
- [ ] 2-5 「감정 (무료)」 → 이름·문화·감정가가 드러나고 「내력」에 발굴·감정이 적힌다.
- [ ] 2-6 다른 유적을 하나 더 발굴해 **두 점**을 만든 뒤 한 점은 「박물관 기증」 → 평판 +10, 사례금. 다른 한 점은 **그대로 가지고 있는다**(4번에서 쓴다).

#### 3. 계약 (5분) — 창 1 ↔ 창 2
- [ ] 3-1 창 2: `/cash`, `/grow 5`, Hollow Crown으로 워프.
- [ ] 3-2 창 1: O 계약 창 → 「운송」, Xenite 10단위, 목적지 아무 성계, 보상 2000 CR → 게시. 지갑에서 2000 CR이 빠진다(공탁).
- [ ] 3-3 창 2: O 계약 창(새로고침) → 그 계약 「수락」. 양쪽에 체결 알림.

#### 4. 배신과 격침 (5분)
- [ ] 4-1 창 2: 창 1의 함선을 목표(T)로 잡고 사격(Space). Hollow Crown은 WILD라 공격 가능.
- [ ] 4-2 첫 명중에 **「계약 상대 … 공격해 계약이 깨졌습니다」**(창 2), **「…계약을 깨고 당신을 공격했습니다 — 보상 …은 당신에게」**(창 1). 창 1 지갑에 2000 CR이 돌아온다.
- [ ] 4-3 창 1 격침 → 「유물이 잔해와 함께 가라앉았습니다」. 창 1은 재건(Enter).

#### 5. 잔해·위조·보도 (8분) — 창 2
- [ ] 5-1 잔해로 날아가 V(조사) → 「증거 n건 확보 … **유물 1점 회수**」. U 정거장 창에서 회수한 유물이 보인다.
- [ ] 5-2 H 연대기 → 「… 격침」 사건 → 내 증거(📁) 옆 「위조…」 → 내용을 고쳐 「위조 사본 만들기」. 같은 출처의 증거가 하나 더 생긴다.
- [ ] 5-3 같은 사건 아래 **기사 송고**: 제목·본문 입력 → 「Herald에 송고」. Herald 맨 위에 기사가 **바이라인(— QA-B 기자)**과 함께 뜬다.
- [ ] 5-4 창 1: H 연대기를 열면(독자) 창 2 지갑에 원고료가 들어온다.
- [ ] 5-5 창 1: 창 2가 만든 위조 사본 옆 「감정 (300 CR)」 → **[위조 판명]**, 「증거 위조 폭로」 사건, 창 2 평판 하락. 그 증거를 인용한 기사가 있다면 **[정정]**으로 바뀐다.

#### 6. 동맹과 영토 (3분) — 창 1
- [ ] 6-1 L 동맹 창에서 동맹 창설(이름·태그) → `/influence 100 3`, `/influence 100 4`.
- [ ] 6-2 L 창에 「성계 영향력」 표(100, 80), 「지배 2곳 · 유지비 150 CR/시간」(금고 0이라 빨간색).
- [ ] 6-3 Orion Drift(3)로 워프하면 HUD 왼쪽 위에 「지배 [태그] (우리 동맹 +10%)」, M 은하 전도에 태그.

#### 7. 연구소·박물관 (3분)
- [ ] 7-1 창 2: 정거장에 도킹 → U 정거장 창 「연구소·박물관」 → 기관 이름 입력 후 「설립 (5000 CR)」.
- [ ] 7-2 회수한 유물 옆 「… 기증」 → 기관에 전시 1점, 펼치면 내력.
- [ ] 7-3 창 1: 같은 성계 정거장에 도킹 → 「… 관람: 전시 1점」 알림, 창 2 지갑 +30 CR.

### 끝나면

- 서버 창에서 Ctrl+C(기록이 끝까지 저장된다).
- 메모를 그대로 전달. 리드가 기록을 재생해 재현·수정한다.
